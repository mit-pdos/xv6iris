# The main theorems of MachCSL/Liveness/, whose axioms the assumption audit
# checks (tools/audit/Audit.lean, run by tools/ci/audit.sh).  One fully
# qualified name per line; `#` starts a comment.
#
# The list is counted, not pinned.  Each theorem may rest on any of Lean's
# three standard axioms (propext, Classical.choice, Quot.sound) and on any
# number of shape-checked bv_decide certificates.  Any other axiom fails the
# audit: sorryAx, a native_decide certificate, a hook axiom of the Sail fork,
# an axiom of the tree.  No statement and no exact axiom set is pinned, so a
# theorem whose statement or proof changes needs no edit here, and a theorem
# that uses fewer axioms passes.  A listed name that no longer exists fails
# the audit: rename it here when you rename it in the source.
#
# These theorems are proofs, not trusted statements.  They are not roots of
# the coverage cone (tools/ci/roots.txt) and not in tools/audit/baseline.json,
# and the audit does not search their cones for `opaque` constants.
#
# The author of every new MachCSL/Liveness/ module adds its main theorems here.
