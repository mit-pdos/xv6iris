# The 30 functions the shell reaches on the input `echo Hello world!\n`
# (claude-notes/projects/user-sh.md has the trace).  Unreachable branches
# INSIDE a listed function are kept -- an unused [uinstr] fact costs only
# compile time, and pruning per branch would have to be re-audited whenever
# the input changes.  A whole function that is never entered is another
# matter: its facts would be a claim about code no proof reads, so it is
# left out and the reason is recorded below, where the generated header
# picks it up.

note This catalog covers the shell as it runs `echo Hello world!\n`: the
note command loop, the parser, the argument-vector builder, the fork/exec
note path, and the allocator underneath them.  Its coverage claim is the
note list of omitted functions above, not all of sh.
