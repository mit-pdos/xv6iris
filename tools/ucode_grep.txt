# ucode_grep.txt -- the pc set of iris/UCodeGrep.v, for tools/gen_ucode.py.
#
# tools/ucode_manifest.json binds this spec to iris/UCodeGrep.v; `make
# gen-ucode` rewrites that file from it, and `make check-ucode` fails if it
# moved.
#
# grep is the first verified program with RECURSION (matchhere calls
# itself and matchstar, matchstar calls matchhere, neither as a tail call)
# and the first to keep state in a global across reads: `buf[1024]`, the
# leftover of a partial line memmove()d to its front.  Its two diagnostics
# go through fprintf (usage, fd 2) and printf (cannot open, fd 1), both
# with at most a %s.
#
# Unreachable branches inside a listed function are kept (ucode_cat.txt's
# rule); whole functions never entered are left out, with the reason.

note This catalog covers grep as it runs: main's walk over argv, the
note read/scan loop in grep(), the matcher (match, matchhere, matchstar),
note the two ulib helpers the loop calls (strchr, memmove), and the
note fprintf/printf cone under its two diagnostics.

skipfunc stat unreachable: grep never stats
