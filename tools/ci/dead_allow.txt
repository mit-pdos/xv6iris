# Extra liveness roots for the dead-code report (tools/find_dead.py): things
# that are deliberately not reached by the top theorems.  Entries:
#   decl <fully.qualified.Name>     one declaration
#   module <Module.Name>            every declaration of a module
#   prefix <Namespace>              every declaration under a namespace
# Everything an entry reaches counts as live ("allowlist").  An entry that
# matches nothing is an error (stale rows do not accumulate).
