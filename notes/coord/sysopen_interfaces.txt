THE DESIGN (read SysOpenParts' header, deviations 1-9)
  * Rocq's stage lemmas (module-functor calls) are PREMISE-PASSING BODIES (the CreateSharedBody
    pattern): each stage file PROVES `⊢ body` for its own body(ies), taking the bodies it calls
    as LEAN HYPOTHESES `(hX : ⊢ sysOpenXBody (hlc := hlc) Γ k A)`, plus `(hS : SysOpenStatic k A)`
    and the callee interface structures it needs (`(IUP : IUNLOCKPUT) (EO : END_OP)` ...,
    the SysLinkTails pattern).  The seal (ProofSysOpen) composes them.  No stage imports another
    stage's file; all import Xv6.SysOpenParts.
  * Bodies are HART-FREE (`∀ c : CPU, … -∗ wpLoop c`), eb-generic (trapCsrsExt c k.sie /
    cpuClaimExt c k.sie k.proc in every body; no eb = true, no lks), over `fsReady` via the
    persistent `sysOpenEnv Γ A` (procsInv, panicEnv, fsReady, isFtable A.γl A.γ).
  * `k` is sys_open's ENTRY context; machine state inside a body is
    `kctx c (((k.withSpie spie spp).pushed 24).withRegs R)` at `pcIs c (sysOpenAddr + off#64)`,
    registers by `⌜sysOpenPins k R s1 s2 s3⌝` (sp = sp0-192, s0 = sp0, s1/s2/s3 the walk's
    current values, s4..s11 = entry), frame = `sysOpenCells (k.regs 2#5) (k.regs 1#5)
    (k.regs 8#5) w3 w4 w5 w6 lo om w24` (slot 3/4/5 = the shrink-wrapped save slots of
    s1/s2/s3: `k.regs 9#5` / `18#5` / `19#5` once saved, junk before) + the path buffer
    (`sysOpenAny (sysOpenPath (k.regs 2#5)) 128`, or `byteBuf … (bview 128 bp)` at the walk
    entries) + `⌜(sysOpenPath (k.regs 2#5)).toNat % 8 = 0⌝` (Rocq so_al).
    The omode cell is `wordPointsTo (sysOpenOmode sp0) 4 (own 1) om` inside the cells, at
    `om = sysOpenOm A = BitVec.extractLsb' 0 32 A.vom` from the walk entries on.
  * The block is at `procAddr A.j` everywhere (rewrite a callee's k.proc with hS.hproc).  After
    argstr it is `sysOpenV2 A P2 = { A.V with upt := P2 }` at `sysOpenM2 A P2 = viewFaulted
    A.V.upt P2 A.M`, with `⌜A.V.upt.extSz A.V.sz P2⌝`.  Callees take the pid cell only:
    `sysOpenPid A = wordPointsTo (pPid (procAddr A.j)) 4 pidPriv A.pid`, lent by
    `sysOpen_pid_fd` / `sysOpen_pid_core` (need `hct : curTier = KTier.kpt`, from `kctx_tier`
    + hS.htier).
  * Every exit leaves through `sys_open_exit` (+0xca, PROVED) with s1/s2/s3 restored to the
    entry's (`sysOpenPins k R (k.regs 9#5) (k.regs 18#5) (k.regs 19#5)`), then a hart-free
    continuation `∀ c' R', ⌜calleeSaved k.regs R' ∧ R' 10#5 = R 10#5⌝ -∗ kctx c' … -∗ …`.
    A failure tail's own continuation is `sysOpenRet k Φ` (Φ keyed on the returned a0).
  * The contract's continuation at the plain arms is `sysOpenPostP k A c`
    (= SpecSysOpen.sysOpenK at openArmsPlain, Rocq so_cont_au/so_cont0_au); at the create arms
    `sysOpenPostC k A Farm Fun Fok Fex c`.  `sys_open_post_pin` turns the contract's
    `wpNext true k.proc cpu (sysOpenK …)` into `∀ c, …`; `sysOpenK_mono` converts ARMS
    (what the CreArm shim needs).
  * The LOCKED NODE is `sysOpenLk γil γisl loc tlc A.pid kk s g inum dn` (iunlock's write-arm
    precondition minus the payload: isSleeplockGen, sleeplockedQ γisl s, credFloor loc tlc,
    icTxDep fscIc kk s icfgDev inum g loc, offRows, iDev/iInum halves, iValid, ityShot g
    dn.diType, ifreezeOff) + the payload (`icLoaded … kk inum dn bm`, or PEELED:
    `sysOpenFlat kk inum dn bm data` = Rocq so_flat) + the kept parent
    `sysOpenKeep kk s g inum` ((∃ lo tl, ⌜lo ≤ tl⌝ ∗ credFloor lo tl ∗ inodeRefShortGenlo kk
    (s + s) s icfgDev inum g lo) ∗ runitAny inum.toNat; Rocq's qi = s).  create's payout
    converts by `sysOpen_of_createLocked`.
  * The AU residue below the fire: `sysOpenResidue A pl inum dn bm data`
    (⌜argPathOf A.M A.v.toNat pl⌝ ∗ A.P (pathElems pl).length inum.toNat ∗
    sysOpenObs A.Fo inum.toNat (eraNode dn bm data) ∗ openTruncPiece (fsGammaL fscFs) A.vom A.Ft).
  * The fd's off cell after the store block: `sysOpenOffCell kf C γo` (FD_INODE: ∃ vo,
    wordAtN curCtx (aFoff kf) 4 (own 1) vo ∗ ⌜offWf vo⌝ ∗ offGv γo 1 vo; else offFree kf 1).

/-! ## §3.  THE SHARED STAGE VOCABULARY -/

/-- The contract's parameters, as ONE record (the `SysLinkArgs` /
`SysMkdirArgs` pattern): the ftable lock's and the file table's names, the
process slot, its pid, the block at ENTRY (`V`, `M`), the two syscall
argument words (`v` the path pointer, `vom` the omode word), the caller's
descriptor view `sts`, the reference allowance `ns`, and the PLAIN side's
four families.  The create side's four (`Farm Fun Fok Fex`) are separate
parameters of the create entry (`sysOpenEntryCBody`): every body below the
join is stated at the plain arms, and the create entry reaches them through
`SysOpenCreArm`'s families (Rocq's `socr_*`, the "shim"). -/
structure SysOpenArgs (GF : BundledGFunctors) where
  γl : GName
  γ : FileNames
  j : Nat
  pid : BitVec 32
  V : ProcPriv
  M : Nat → List (BitVec 8)
  v : BitVec 64
  vom : BitVec 64
  sts : List FdState
  ns : Nat
  P : Nat → Nat → IProp GF
  Pmiss : Nat → Nat → IProp GF
  Fo : Pfam GF (Aview → Nat → Anode → IProp GF)
  Ft : Pfam GF (Aview → Nat → List (BitVec 8) → IProp GF)

/-- THE STATIC PREMISES (Rocq's `K_sys_open <= K -> … -> eb = true ->`
block, minus `eb`): the contract's own, fixed for the whole call.  `k` is
sys_open's ENTRY context. -/
structure SysOpenStatic (k : KCtx) (A : SysOpenArgs GF) : Prop where
  hj : A.j < NPROC
  hproc : k.proc = procAddr A.j
  htier : k.tier = KTier.kpt
  hnoff : k.noff = 0
  hK : sysOpenSlots ≤ k.avail
  hns : sysOpenIrefs ≤ A.ns
  hv0 : A.V.tf[tfArgIdx 0]? = some A.v
  hv1 : A.V.tf[tfArgIdx 1]? = some A.vom

/-- The block after argstr: the page table grown to `P2`, the view faulted
(argstr's post; Rocq's `us_upt U P2`). -/
abbrev sysOpenV2 (A : SysOpenArgs GF) (P2 : UPtd) : ProcPriv := { A.V with upt := P2 }
abbrev sysOpenM2 (A : SysOpenArgs GF) (P2 : UPtd) : Nat → List (BitVec 8) :=
  viewFaulted A.V.upt P2 A.M

/-- `omode` as argint stored it. -/
