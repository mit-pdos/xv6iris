## Method (why not grep?)

A `Require Import M` can be needed even when **no name from `M` is written** in the
file, because `M` may provide typeclass `Instance`s, `Notation`s, `Hint`s
(auto/eauto/autorewrite), `Canonical Structure`s or `Coercion`s — none of which
appear as name references in `.glob`. So a pure glob/grep "is any name used?"
check yields **false "unused" verdicts**. The only reliable test is: remove the
import, recompile, see if it still builds.

The tool therefore:
1. **Parses** each `.v` for `Require Import` / `From X Require Import` statements
   and maps every module token to its full logical path (respecting `_CoqProject`'s
   `-R . xv6iris`, `-R ../model-xv6iris Riscv`, `-R ../kernel-rocq Kernel`).
2. **Shortlists** candidates from `.glob`: an import is a *candidate* only if its
   module contributes no non-`lib` `R` reference (the `Require Import` line itself
   emits a `lib` self-reference, which is excluded). This just narrows the set.
3. **Build-confirms** each candidate with `coqc` (which, unlike `make`, never
   rebuilds dependencies — every test is hermetic): first remove ALL candidates in
   a file at once; if that compiles they are all removable, else fall back to one
   at a time, then confirm the surviving set drops **jointly**. Files are always
   restored to their original bytes and their `.vo` rebuilt, leaving the tree green.

**`Require Export` caveat:** removing an `Export` can break *downstream* files, so a
single-file `coqc`/`make` is insufficient to prove it removable. The three Export
lines here (`WpEntry.v`, `WpGprCsrr.v`, `WpGprCsrw.v`) were **skipped** and are NOT
part of the counts below. (Testing them soundly needs a full `make`.)

**Shortlist limitation:** if a name defined in `M` is referenced but is *also*
reachable through another (transitive) import, glob still attributes the reference
to `M`, so `M` is not shortlisted and a genuine removal can be missed. The counts
below are thus a sound **lower bound** on removable imports. (`--all` build-tests
every import to close this gap, at the cost of many more compiles.)

drop-set until it compiled, so the set listed below is still build-confirmed as
jointly removable; the imports it had to keep are counted under NEEDED.
