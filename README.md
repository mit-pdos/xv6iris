# xv6iris — verifying xv6-riscv in Rocq/Iris over the Sail RISC-V semantics

This project proves, in the [Rocq Prover](https://rocq-prover.org/) with the
[Iris](https://iris-project.org/) separation logic, weakest-precondition
specifications for the [xv6-riscv](https://github.com/mit-pdos/xv6-riscv)
kernel — reasoning about the *actual kernel binary*, instruction by
instruction, against the official [Sail RISC-V](https://github.com/riscv/sail-riscv)
ISA semantics compiled to Rocq. The kernel ELF is disassembled into Rocq data,
an Iris `language` is built over the Sail model's execution monad, and machine
code is specified with separation-logic points-to assertions for registers,
memory, and devices.

## Layout

```
xv6iris/
├── xv6-riscv/       # the kernel sources + built kernel/kernel ELF
├── model-xv6iris/   # the Sail RISC-V model compiled to Rocq (checked in; logical name `Riscv`)
├── kernel-rocq/     # the kernel image as Rocq data, generated by the dumper (logical name `Kernel`)
├── iris/            # the Iris development: language, points-to, WP lemmas, function specs & proofs
├── tools/           # dump_kernel.py (ELF -> Rocq), proof_coverage.py, proof_profile.py, regen_sail_model.sh
├── claude-notes/    # the durable development notes (design docs, worklists) — see below
└── Makefile         # top-level build
```

## Build

Everything is driven by the top-level `Makefile`, which runs all Rocq commands
inside the project-local opam switch, so you do **not** need to
`eval $(opam env …)` yourself.

```sh
make            # == make proofs: build the model, the kernel dump, and all Iris proofs
make model      # compile only model-xv6iris/ (the Sail-generated Rocq model)
make kernel     # build the xv6 kernel ELF (xv6-riscv/kernel/kernel)
make dump       # regenerate kernel-rocq/*.v from the ELF, then compile kernel-rocq/
make clean      # remove Rocq build artifacts; make distclean also cleans the xv6 tree
```

Build graph: the xv6 ELF is disassembled by `tools/dump_kernel.py` into
`kernel-rocq/*.v`; `iris/` depends on both `kernel-rocq/` and the Sail model in
`model-xv6iris/`. Toolchain (in the opam switch): Rocq 9.0.1, coq-iris 4.4.0,
coq-sail-stdpp 0.20.1, plus `riscv64-linux-gnu-gcc`/`objdump` and `python3`
for the kernel and dumper.

### Regenerating the Sail model

The generated model `.v` files in `model-xv6iris/` are checked in; a normal
build never regenerates them. To regenerate (needs the `sail` compiler 0.20.1
with `sail_coq_backend`, and a `sail-riscv` checkout), run
`tools/regen_sail_model.sh` — or `make model-gen`, which prints instructions if
`sail` is missing. The model is generated from this repo's own config,
`model-xv6iris/sail-config-rv64d.json`; the comment at the top of that file
documents the one deliberate deviation from the upstream default.
